# Capturing Vision - Photography Website

A modern, responsive photography portfolio website built with HTML, CSS, and JavaScript. This website showcases the work of Capturing Vision, a professional photography service.

## 🌟 Features

- 🎨 Modern and Responsive Design
- 🌓 Light/Dark Mode Toggle
- 📱 Mobile-Friendly Interface
- 📸 Photo Gallery
- 📧 Contact Form with Email Integration
- 🔗 Social Media Integration
- 🎯 Smooth Navigation
- ✨ Interactive UI Elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Typed.js for Text Animation
- SweetAlert2 for Notifications
- SMTP.js for Email Functionality

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Capturing-Vision.git
```

2. Open `index.html` in your web browser to view the website.

## 📧 Contact Form Setup

The contact form uses SMTP.js for sending emails. To set up your own email service:

1. Sign up for an Elastic Email account
2. Replace the following credentials in the `index.html` file:
   - Host
   - Username
   - Password
   - To email address
   - From email address

## 🎨 Customization

- Colors can be customized in `css/3. color-1.css`
- Images can be replaced in the `images/` directory
- Social media links can be updated in the navigation bar
- Contact information can be modified in the contact section

## 📱 Responsive Design

The website is fully responsive and works on:
- Desktop
- Tablet
- Mobile devices
